A property listed here becomes a required tool argument unless you leave the field blank.

Skills, MCP servers and plugins are stored through one pluggable backend. file needs nothing; supabase and postgres (Neon, Supabase, Railway) make them survive a redeploy — and give the agent a real sql tool.

run a statement 

      

      

        point this host at a database
        
NOVA_STORE_BACKEND=supabase
NOVA_STORE_URL=https://<project>.supabase.co
NOVA_STORE_KEY=<service_role key>

# or a DSN — Neon, Supabase, Railway, anything Postgres:
NOVA_STORE_BACKEND=postgres
NOVA_STORE_URL=postgresql://user:pass@host/db
NOVA_STORE_READONLY=1        # optional: sql tool becomes SELECT-only

        The postgres backend needs pip install asyncpg; supabase
          does not (it uses the REST API).
